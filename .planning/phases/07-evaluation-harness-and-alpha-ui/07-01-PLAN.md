# Phase 07 Plan 01: Eval Contracts, Gold-Set Loader, and Metrics Harness

## Objective

Build the executable eval foundation: gold-label schema, loader, point-aware matcher, per-event metrics, and honest blocked-state reporting for incomplete real gold data.

## Tasks

1. Add `src/sva/eval/` contracts and deterministic metrics.
2. Add a harness that scores canonical predicted events against a gold manifest and reports readiness honestly.
3. Add CLI entrypoint(s) for running the harness locally.

## Verification

- `./.venv/bin/pytest tests/test_eval_contracts.py tests/test_eval_metrics.py tests/test_eval_harness.py -q`
- `./.venv/bin/python -m py_compile src/sva/eval/gold.py src/sva/eval/metrics.py src/sva/eval/harness.py`

## Done When

- Per-event precision/recall is computed without hiding behind macro averages.
- Incomplete real-gold manifests report blocked state instead of pass/fail.
- The repo has a stable eval package ready for later gating.
