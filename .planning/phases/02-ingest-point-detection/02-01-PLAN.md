<objective>
Expand Phase 1's local-file ingest into a shared Phase 2 source-intake service that accepts both local files and approved public URLs, logs required rights acknowledgments, and exposes the capability through both CLI and a thin synchronous FastAPI surface.

Purpose: This plan satisfies the ingest half of Phase 2 without accidentally pulling in Phase 6 async job orchestration. It establishes the rights-safe URL boundary and keeps one normalization path for all sources.

Output: A developer can submit either a local file or an approved public URL, receive normalized ingest metadata back, and verify that URL submissions are blocked unless allowlist validation and rights logging both pass.
</objective>
