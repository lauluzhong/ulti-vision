<objective>
Implement the dedicated point-detection stage for full-game ingest, persist stable point rows with evidence, and keep the detector honest by using cheap VLM only as a tie-breaker on ambiguous boundary intervals.

Purpose: This plan satisfies the point-boundary half of Phase 2 and creates the canonical source of truth that later phases rely on for point-scoped windows, events, exports, and eventual UI correction.

Output: Given an ingested game, the system can produce persisted point rows with stable `point_id` values, start/end timestamps, confidence, and inspectable evidence before any per-point perception runs.
</objective>
