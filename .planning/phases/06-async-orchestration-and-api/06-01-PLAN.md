| Orchestrator -> provider adapters | Expensive external calls can be duplicated if resume boundaries are wrong. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-01 | T | `src/sva/jobs_dao.py` | mitigate | Persist explicit stage/status values and bounded per-point progress rows so worker retries cannot scribble arbitrary lifecycle state into `jobs`. |
| T-06-01-02 | D | `src/sva/orchestration.py` | mitigate | Make observation rows the committed VLM checkpoint and consult cached observations before every provider call, preventing duplicate completed-window work on restart. |
| T-06-01-03 | R | job lifecycle timestamps | mitigate | Store durable started/completed/error timestamps in the lifecycle seam so retries and failures remain auditable outside broker logs. |
</threat_model>
