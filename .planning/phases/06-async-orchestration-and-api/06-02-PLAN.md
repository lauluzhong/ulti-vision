<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> submission route | Untrusted upload/url/caller input becomes durable background work. |
| Client -> status route | Public polling reads internal progress state derived from worker execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-01 | T | `POST /ingest` | mitigate | Reuse exact one-source and rights-ack validation from the existing route before durable job creation or queue enqueue. |
| T-06-02-02 | D | submission path | mitigate | Return `202 Accepted` after durable enqueue and never perform transcode/perceive/interpret inside the request cycle. |
| T-06-02-03 | I | `GET /jobs/:id` | mitigate | Status responses project canonical stage/progress summaries only and exclude raw provider payloads, secrets, or queue-internal metadata. |
</threat_model>
